# Cloudflare Workers

STOP. Your knowledge of Cloudflare Workers APIs and limits may be outdated. Always retrieve current documentation before any Workers, KV, R2, D1, Durable Objects, Queues, Vectorize, AI, or Agents SDK task.

## Docs

- https://developers.cloudflare.com/workers/
- MCP: `https://docs.mcp.cloudflare.com/mcp`

For all limits and quotas, retrieve from the product's `/platform/limits/` page. eg. `/workers/platform/limits`

## Commands

| Command | Purpose |
|---------|---------|
| `npx wrangler dev` | Local development |
| `npx wrangler deploy` | Deploy to Cloudflare |
| `npx wrangler types` | Generate TypeScript types |
| `npx wrangler kv namespace create STATUS_KV` | Create the state KV namespace |
| `npx wrangler secret put CF_API_TOKEN` | Set the Cloudflare API token |
| `npx wrangler tail` | Live logs |

Run `wrangler types` after changing bindings in wrangler.jsonc.

## Project-specific

This Worker uses the Cloudflare REST API to add/remove a Workers Route on
the same zone in response to a cron-triggered probe. Relevant docs:

- Workers Routes API: https://developers.cloudflare.com/api/resources/workers/subresources/routes/
- Cron Triggers: https://developers.cloudflare.com/workers/configuration/cron-triggers/
- API token permissions: the token needs **Workers Routes: Write** on the target zone.
